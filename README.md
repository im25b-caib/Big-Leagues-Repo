# Big Leagues

## Running the game locally

1. Clone the repository 
2. Open two terminals in this directory:

```bash
npm run server
```

```bash
npm run dev
```

3. Open the Vite URL in two browser tabs to join the same lobby. 

Enjoy! 

## Keybinds 
- W/A/S/D - Movement 
- F - Shooting the ball
- E - tackle
- Q - Dribble / dodge tackle
