# Big Leagues

## Run locally

Open two terminals in this directory:

```bash
npm run server
```

```bash
npm run dev
```

Open the Vite URL in two browser tabs to join the same lobby. Move with W/A/S/D.


## Keybinds 
- W/A/S/D - Movement 
- F - Schiessen
- E - Grätsche
- Q - Ausweichen einer Grätsche
